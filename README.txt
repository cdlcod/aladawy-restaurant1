# قصر العدوي للمشويات

افتح `index.html` مباشرة في المتصفح.

## الملفات
- index.html
- style.css
- script.js
- assets/

## مهم
في `script.js` غيّر:
const phone = "201000000000";
إلى رقم واتساب المطعم بصيغة دولية بدون علامة +.

الموقع يحتوي على:
- شعار المطعم المرفوع
- المنيو كاملة حسب الصور المرفوعة
- بحث وفلاتر
- كروت وجبات متحركة
- سلة طلبات
- حفظ السلة في LocalStorage
- إرسال الطلب على WhatsApp
- تصميم Responsive للموبايل والكمبيوتر
